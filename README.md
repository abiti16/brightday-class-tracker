# Brightday Class Tracker

Build a professional, responsive Student Attendance Management System for a school.



The application should include the following features:



1. Admin Dashboard



- Total number of students

- Total classes

- Present students today

- Absent students today

- Late students today

- Attendance percentage

- Attendance summary charts



2. Student Management



- Add new students

- Edit student information

- Delete students

- Student ID, full name, gender, grade, class, and phone number

- Search and filter students



3. Class Management



- Create grades and classes

- Assign students to classes

- View students by class



4. Attendance Management



- Select date and class

- Display all students in the selected class

- Mark students as Present, Absent, or Late

- Save attendance records

- Allow authorized corrections to attendance records

- Prevent duplicate attendance records for the same student and date



5. Reports



- Daily attendance reports

- Weekly attendance reports

- Monthly attendance reports

- Individual student attendance history

- Calculate attendance percentages

- Export reports to PDF and Excel



6. User Authentication



- Secure admin login

- Role-based access for administrators and teachers

- Protect student information



7. Design



- Modern professional dashboard

- Clean blue and white color scheme

- Responsive design for computers, tablets, and mobile phones

- Sidebar navigation

- Easy-to-use attendance tables



Technical requirements:



- Use a reliable relational database.

- Implement secure authentication and database permissions.

- Validate all forms.

- Include sample demonstration data.

- Make all buttons and features functional, not just visual prototypes.



Build the application step by step and ensure that all modules work together.
